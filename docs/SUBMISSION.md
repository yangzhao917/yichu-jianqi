## 已放入仓库

- 完整项目代码：`apps/web`、`apps/api`、`scripts`

- 项目说明与产品定义：`README.md`、`docs/PRD.md`
- 用户访谈与市场研究：`docs/research/`
- 路演 PPT：`一触见企/一触见企.pptx`
- Pixelle-Video 源码基座：`video-agent` Git 子模块

## 运行入口

```bash
npm install
npm run db:seed
npm run dev
```

Web：`http://localhost:3000`

API：`http://127.0.0.1:3001`

管理员登录需要在 `apps/api/.env` 配置阿里云号码认证服务凭据；凭据不会提交到仓库。

## 仍需单独准备

- 作品演示视频：按通知要求录制，时长不超过 8 分钟。
- 参赛附件：作品信息表、原创性与授权承诺书，以及需要时提交的系统架构图、工作流程图、测试用例与结果。

本清单只记录仓库内的提交材料状态，不代替赛事平台的最终上传和封包操作。
